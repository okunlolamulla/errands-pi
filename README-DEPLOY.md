# Errand Boys API
Node.js + Express. Deploy on Hostinger as a Node.js web app (import this repo from GitHub).
- Framework: Express. Node 20 or 22. Start: `npm start` (src/server.js). Leave PORT unset.
- Set the environment variables in hPanel (see .env.example). Never commit real keys.
- Database scripts are in `database/` (run supabase-setup.sql once in Supabase).
